# Contributing

Thanks for helping students. Read this before opening a PR.

1. **Sources first.** Official facts → official URLs (`gate2027.iitm.ac.in`). Editorial guides label uncertainty. Never auto-publish official dates from memory.
2. **Original work only.** No coaching PDFs, paid explanations, or copied banks. Original questions preferred; PYQs are linked, not republished en masse.
3. **Small, verifiable PRs.** One topic / tool / fix at a time. Fill the PR template.
4. **Checks must pass:** `npm run typecheck`, `npm run validate:data`, `npm run test`, `npm run build`.
5. **No fake completeness.** No dead buttons, fake counts, fake rankings, or "coming soon" as a feature.

Review pipeline: draft → source check → technical review → copyright check → build → publish → periodic review.
