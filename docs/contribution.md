# Contribution guide (maintainer notes)

See `CONTRIBUTING.md` for the short version.

- Content types: Exam, Paper, Subject, Topic, Guide, OfficialUpdate, Resource, Question, StudyPlan, FAQ, Tool, ChangelogEntry, Source.
- Topic template: what / why / prerequisites / concepts / mental model / formulas / mistakes / worked example / practice / PYQ refs / revision checklist / related / sources.
- Beginner mode: show minimum prerequisites only.
- Resource rule: 1 primary + 1 practice + 1 backup per subject, each with a "why".
