# Roadmap

Ordered by student value ÷ maintenance cost. No promises of ranks, traffic, or dates.

## Next (high value, low cost)

1. Grow the bank to 100+ original questions (CS/EC first) with the existing schema — unlocks real full-length mocks.
2. Add 10–15 more topic lessons following `TopicDetail` template; link syllabus rows.
3. Beginner-mode pruning: minimum-prerequisite hints per lesson.

## Later (needs real usage first)

4. Cloudflare Workers + D1 only for cross-device sync (opt-in); local-first stays default.
5. Community moderation queue for submitted questions/resources.
6. Regional-language lesson variants via contributor PRs.

## Explicitly not planned

Accounts for core content, AI chatbot as the product, video hosting, paid funnels, rank predictors, custom domain before the site earns it.
